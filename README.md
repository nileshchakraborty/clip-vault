# ClipVault — Native macOS Clipboard Manager

A blazing-fast, privacy-first, RAM-only clipboard history manager built natively for macOS with SwiftUI and Swift 6.

Designed specifically to avoid the memory bloat, disk leakage, and security risks common to traditional clipboard managers.

---

## 🌟 Key Features

* **Strict Memory-Capped History (Last $N$ Items)**:
  * Choose preset capacities: `5`, `10`, `15`, `20`, `25`, `30`, `40`, `50`.
  * Enter custom integer limits (clamped strictly between $1$ and $50$).
  * Proactive **High Capacity Warning** when $N > 25$ advising on sensitive data lingering and RAM impact.
* **📌 Dedicated Pin Board**:
  * Pin important code snippets, boilerplate text, commands, hex colors, and URLs.
  * Pinned items stay accessible at the top and are never pushed out by new copies.
* **Pure Ephemeral Lifecycle (Zero Disk Footprint)**:
  * All clipboard items reside in RAM.
  * Closing or restarting the application completely purges all unpinned history.
  * Optional user opt-in toggle in Settings: *"Persist Pinned items across app restarts"*.
* **Granular Deletion & Global Clear**:
  * Single-item deletion via hover/right-click.
  * Clear Recent History (preserves Pinned items) or Clear All (including Pinned items).
* **Rich Content Type Detection**:
  * Plain text, formatted Rich Text (RTF), URLs with domain formatting, Hex color swatches, and images (with auto thumbnails and 5 MB memory caps).
* **Password Manager Shielding**:
  * Automatically ignores clipboard events with `org.nspasteboard.ConcealedType` or `AutoGeneratedType` (1Password, Bitwarden, KeePassXC, Apple Keychain).
* **Dual Access Experience**:
  * **Menu Bar Popover**: Lives in the macOS menu bar for single-click access.
  * **Floating HUD Palette**: Spotlight-style centered floating HUD window triggered globally via `⌘ + ⇧ + V`.
* **Legal & Information Views**:
  * Integrated **About Me**, **Terms of Service (MIT)**, and **Privacy Notice** views in Settings.

## ⌨️ Shortcuts & Navigation

| Shortcut | Action |
|---|---|
| `⌘ + ⇧ + V` | Open / Toggle Floating HUD palette |
| `⌘ + 1...9` | Directly copy top 9 recent clips |
| `Click Row` | Copy clip to system pasteboard with feedback |
| `Return` | Copy selected clip and dismiss HUD |
| `Esc` | Dismiss Floating HUD |
| `Right Click` | Open Context Menu (Pin/Unpin, Copy, Delete, Open URL) |

## 🛠 Building & Running

### Requirements
* macOS 14.0 Sonoma or macOS 15.0+ Sequoia
* Xcode 15+ (Swift 5.9 / Swift 6)
* `xcodegen` (optional, for regenerating `.xcodeproj`)

### Generate Project & Build
```bash
# Clone the repository
git clone https://github.com/nileshchakraborty/clip-vault.git
cd clip-vault

# Generate Xcode project (if modified)
xcodegen generate

# Build Release App
xcodebuild -project ClipVault.xcodeproj -scheme ClipVault -configuration Release -derivedDataPath ./build build

# Run unit tests
xcodebuild test -project ClipVault.xcodeproj -scheme ClipVault -destination 'platform=macOS'
```

The compiled application will be located at `build/Build/Products/Release/ClipVault.app`.

## 🔒 Privacy & Security

ClipVault makes **ZERO** network requests and contains **NO** telemetry, tracking, or crash analytics. It operates strictly locally on your Mac.
