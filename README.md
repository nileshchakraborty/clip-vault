## 💡 Why ClipVault?

Most clipboard managers on macOS are either heavy electron wrappers, consume hundreds of megabytes of disk space recording unencrypted copy logs, or phone home with background telemetry.

**ClipVault takes the opposite approach:**
1. **Volatile RAM-Only Storage**: By default, clipboard history lives **strictly in RAM**. All unpinned items vanish upon quitting the app or restarting your Mac.
2. **Hard Upper Bound ($N \le 50$)**: Never lets your clipboard grow into an unmanageable database. Choose presets (5, 10, 15, 20, 25, 30, 40, 50) or custom integer limits.
3. **High Capacity Warnings ($N > 25$)**: Proactively informs you when storing higher quantities could hold sensitive clips in memory longer.
4. **Sub-Millisecond Speed**: 0.2s adaptive polling, background worker payload extraction, pre-indexed 15,700 QPS search, and hardware-accelerated micro-thumbnails.
5. **Zero Telemetry / 100% Local**: No network requests, no crash beacons, no analytics.

## 🌟 Key Features

### 📌 Dedicated Pin Board
* Save boilerplate text, recurring commands, color palettes, and critical snippets.
* Pinned items sit at the very top of your HUD and popover.
* Pinned items never get pushed out by new copies.
* Clear Recent History preserves your pinned board; Clear All wipes everything.
* Optional setting toggle: *"Persist Pinned items across app restarts"*.

### 🔍 Auto-Focus Search & Keyword Highlighting
* **Auto-Focus**: The search bar automatically focuses upon opening the popover or floating HUD.
* **Instant Keyword Highlighting**: Occurrences of your search query in preview text are highlighted in a bright yellow marker pill (`#FFE600`).
* **Dedicated Search View**: Real-time match count with a one-click `Clear` button.
* **Filter Chips**: Filter by `Text`, `Links`, `Colors`, or `Images`.

### 🎨 Vibrant Animated Hover Actions
Each clip row displays interactive, glowing action buttons on hover:
* 📌 **Pin Button**: Illuminates with an amber halo, scaling smoothly with spring physics.
* 📋 **Copy Button**: Illuminates with an electric blue halo.
* 🗑️ **Delete Button**: Illuminates with a crimson red halo.

### 🛡️ Password Manager Shielding
* Automatically inspects system pasteboard types for concealment markers:
  * `org.nspasteboard.ConcealedType`
  * `org.nspasteboard.AutoGeneratedType`
  * `com.agilebits.onepassword` / `com.bitwarden`
* Password manager copies are **completely ignored** and never stored.

### 🖼️ Real-World 60 MB Web Image Resilience
* Accepts large web images, screenshots, and wallpapers up to **60 MB**.
* **Tiered LRU Image Cache**: Retains full raw data for the top 3 images only; older items retain 96px pre-compressed JPEG micro-thumbnails (<5 KB).
* Eliminates bitmap memory bloat, capping process RSS memory to a flat plateau.

## 📦 Installation

### Option 1: Homebrew (Recommended)

```bash
# One-line install
brew install --cask nileshchakraborty/clipvault/clipvault

# Or tap first:
brew tap nileshchakraborty/clipvault
brew install --cask clipvault
```

### Option 2: Standalone DMG
1. Download [`ClipVault-1.0.0.dmg`](https://github.com/nileshchakraborty/clip-vault/releases/latest/download/ClipVault-1.0.0.dmg).
2. Open the DMG and drag **ClipVault** to `/Applications`.
3. Launch `ClipVault` from Launchpad or Spotlight.

## 🧪 Tests & Chaos Hardening

ClipVault includes an adversarial chaos harness testing against real-world attack vectors:

```bash
# Run the 14 automated unit & chaos tests
xcodebuild test -project ClipVault.xcodeproj -scheme ClipVault -destination 'platform=macOS'

# Run the live adversarial pasteboard bombardment harness
swift scripts/chaos_harness.swift

# Run the real multi-megabyte web asset stress harness
swift scripts/web_asset_chaos.swift
```

### Chaos Vectors Survived:
1. **Pasteboard Bombardment**: 300 sequential copies at 20ms intervals (~42 copies/sec).
2. **Megabyte Bombs**: 20 MB text files + 48 MB raw TIFF images.
3. **Parser Fuzzing**: 3,000 unclosed nested RTF loops, null bytes, and corrupt image binaries.
4. **Corrupt Disk Recovery**: Gracefully handles truncated JSON without startup crashes.
5. **Memory Leak Detection**: Zero leaks confirmed via Apple's `/usr/bin/leaks`.

## 🛠 Building from Source

### Requirements
* macOS Sonoma 14.0+ or Sequoia 15.0+
* Xcode 15+ (Swift 5.9 / Swift 6)
* `xcodegen` (`brew install xcodegen`)

```bash
# 1. Clone repository
git clone https://github.com/nileshchakraborty/clip-vault.git
cd clip-vault

# 2. Generate Xcode project
xcodegen generate

# 3. Build Release App & DMG
./scripts/package_dmg.sh
```
